# Quickstart

Install dependencies and run tests:

```bash
npm test
```

The baseline project intentionally stays small so GitHub bot output is easy to inspect.

## Files

- `src/security.js` contains permission and environment filtering helpers.
- `src/pricing.js` contains discount calculation logic.
- `test/*.test.js` covers the baseline behavior.
